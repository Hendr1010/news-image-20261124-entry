# news-image-20261124-entry

One image summing up the world's news of Tuesday, 24 November 2026, as a
broadsheet front page.

- **Lead story:** Ukraine says its naval drones sank the Russian corvette
  Merkury at Benghazi, Libya, and hit the cargo ship MV Angara.
- **Russia warns Estonia** it is "on the verge of triggering open war" as
  border closures and airspace incidents rattle NATO's eastern edge.
- **COP31 collapses in Antalya** after 90+ nations reject a draft that never
  mentioned fossil fuels.
- **US–Iran standoff deepens at Hormuz**, with naval patrols stepping up.
- **Nvidia reinstates Jensen Huang as chief executive.**

## How it works

`main.ts` (Node 22, standard library only) copies the bundled `entry.png`
(1024×1024, under 1 MiB) to `/output/entry.png`. The program runs twice and
writes identical bytes both times; it uses no network.
